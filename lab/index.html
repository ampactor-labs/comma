The lab.

The main page explains the idea: the piano's tuning errors can be used as a small memory and computer. These eight pages test that idea further, connect it to other fields, and measure things the main page only states.

Each page runs in your browser with nothing to install, and none of them sends data anywhere. They all use the same oscillator bank as the main page, and a test script checks that their results match it exactly.

Not built yet

Some experiments need physical equipment. Here is what remains and how far each one has got.

  • A real piano as the reservoir. The listening test page can already measure a real piano's beat rates through a microphone. The next step is to record a detuned upright piano and fit the readout to the recording.
  • Writing a letter into a real tuning. The tuning-channel page does the coding and the arithmetic. Doing it for real needs a strobe tuner, a piano, and a tuner willing to set the deviations.
  • The bank on a breadboard. The build sheet gives the circuit and every component value, worked out from the piano's detunings. It has not been built.
  • Metronomes on a real plank. The page simulates them. Five metronomes, a board and two cans as rollers would show whether real letters fail in the order the simulation predicts.
  • The sunflower itself. The comodulogram page is ready to analyze a recording. The recording protocol is in the plant note.
  • A spoken-digit benchmark. Done as a script rather than a page: tools/digits.mjs, run on the Free Spoken Digit Dataset. Given only the loudness of each spoken digit, the readout alone gets 26% right and the piano's bank raises that to 50%. With the bank's errors set to zero it falls back to 26%, the same as no bank. Given eleven frequency bands instead, the readout gets 91% on its own and the bank adds nothing. The errors help most when the input carries little information.
  • Identifying a tuner from a recording, two banks coupled to each other, a commit hash stored in the register. Not started.

The shared code is lab/kit.js: the main page's bank with the detunings passed in, plus tunings, a frame-sliced experiment runner, and the sound and canvas plumbing. node tools/verify.mjs checks that it reproduces the main page and checks the claims these pages make. Pages that open the microphone ask first, and need the site served over https on a phone.
