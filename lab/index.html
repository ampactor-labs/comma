The comma · past the end of the pavement

The back country.

The main page is the paved overlook: park, look at the view, read the sign, drive home. These pages are the trails behind it. They're rougher, they go further, and a couple of them go places nobody has bothered to go before. Bring water.

Every one of them runs in your browser with nothing to install, the same as the main page. None of them sends anything anywhere. The bank they share is the main page's bank, checked to the last digit by the same script that checks the main page.

—

Trails not yet cut.

Some of the best ideas need things a web page doesn't have: hands, solder, a piano, a sunflower, an afternoon. Here's what's waiting, and how far each one got.

  • A real piano as the reservoir. The listening test page can already hear a real piano's beat rates through a microphone. The next step is a full recording session with a detuned upright and the readout fit on that, which needs an upright.
  • Writing a letter into a real tuning. The tuning-channel page does the coding and the arithmetic. Doing it for real needs a strobe tuner, a cooperative piano owner, and a professional tuner willing to be the villain.
  • The bank on a breadboard. The build sheet has the circuit and every component value worked out from the piano's detunings. Nobody has soldered it.
  • Metronomes on a real plank. The page simulates them. Five metronomes, a board, and two soda cans would settle whether the letters die in the order the simulation says.
  • The sunflower itself. The comodulogram page is the analysis, waiting for a recording. The protocol is in the plant note.
  • A spoken-digit benchmark. Not done. It needs a dataset of recorded digits, and the machine this was built on couldn't fetch one. It would be the first honest number for how this bank does on a real task, and the number would probably be poor.
  • Tuner forensics, dueling banks, a commit hash buried in the register. Still in the notebook.

The shared code is lab/kit.js: the main page's bank with the detunings passed in, plus tunings, a frame-sliced experiment runner, and the sound and canvas plumbing. node tools/verify.mjs checks that it reproduces the main page and checks the claims these pages make. Pages that open the microphone ask first, and need the site served over https on a phone.
